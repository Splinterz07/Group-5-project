


**Planning and Analysis **

## Introduction / Overview

Bookify is an online event booking system designed to help users discover, explore, and reserve tickets for events easily. The platform also enables event organizers (admins) to create and manage events efficiently.

The system aims to centralize event discovery and simplify the booking process for users.

## Business Need

Many users face difficulty finding and booking events due to fragmented platforms and manual processes. Event organizers also lack a centralized system to manage their events and attendees effectively.

## Business Value

- Reduces time required to find and book events 

- Centralizes event discovery in one platform 

- Improves user experience and engagement 

- Enables organizers to efficiently manage events and bookings

## **Target Users**

- **General Users (Attendees):** Individuals looking to discover and book events 

- **Event Organizers (Admins):** Individuals or organizations creating and managing events

## **System Scope**

### In Scope

- User registration and login 

- Event browsing and searching 

- Ticket booking system 

- Booking history tracking 

- Event management by admins 

### Out of Scope (for now)

- Advanced analytics dashboard 

- Social media integrations 

- Multi-language support 

## **Functional Requirements**

### User Functional Requirements

- Users can create an account and log in securely 

- Users can view and update their profile 

- Users can browse upcoming events 

- Users can search and filter events by name and category 

- Users can select and book tickets for events 

- Users can view their booking history 

- Users receive email confirmation after booking

### **Admin Functional Requirements**

- Admins can create, edit, and delete events 

- Admins can define: 

  - Event name 

  - Date and time 

  - Location 

  - Ticket price 

  - Ticket quantity 

- Admins receive email confirmation when an event is created 

- Admins can view bookings for their events 

### **Booking System Functional Requirements**

- Users can select events 

- Users can choose ticket types (e.g., Regular, VIP, VVIP) 

- System calculates total price based on ticket quantity 

- System displays a booking confirmation page 

- System sends confirmation emails after successful booking

## **Non-Functional Requirements**

- System should support multiple users concurrently 

- Response time should be less than 3 seconds for key actions 

- User data must be securely stored (e.g., encrypted passwords) 

- System should be available 24/7 with minimal downtime 

- Email notifications should be reliable and timely 

## **System Interfaces / UI Pages**

- **Home Page:** Event listings, search bar, featured events 

- **User Profile Page:** Profile settings and booking history 

- **Event Details Page:** Full event information and booking options 

- **Booking Page:** Ticket selection, total price, confirmation 

- **Admin Dashboard:** Event management (create, edit, delete) 

- **Payment Page:** Handles transaction process using third-party payment platforms

## **UI/UX Considerations**

- Minimalist design 

- Color scheme: 

  - Primary: Black 

  - Secondary: White 

  - Accent: Blue 

- Clean and intuitive navigation 

- Responsive design for different screen sizes

## **Assumptions & Constraints**

- Users have internet access 

- Email service integration is available 

- Payment processing depends on third-party services
